# День 16. Подключение MCP

В проект добавлен минимальный локальный пример MCP-клиента и MCP-сервера.
Он не использует внешний сервис, ключи или учётные записи: поэтому его можно
безопасно запустить сразу после установки зависимостей.

## Что происходит

```text
server/mcp-client.ts
        │
        │ StdioClientTransport + MCP initialize handshake
        ▼
server/mcp-demo-server.ts
        │
        ▼
Инструмент greet
```

1. `mcp-client.ts` запускает локальный сервер как дочерний процесс и
   устанавливает с ним соединение через `stdio`.
2. Сервер регистрирует инструмент `greet` с описанием и JSON-схемой входных
   параметров, а также `get_current_time` и `calculate_sum`.
3. Клиент вызывает `client.listTools()` и выводит имя и описание каждого
   доступного инструмента.
4. После подключения клиент ждёт команду пользователя. Только по команде он
   вызывает соответствующий инструмент через `client.callTool()`.
5. В `finally`
   клиент закрывает соединение и дочерний процесс сервера.

## Запуск

```bash
npm run mcp:demo
```

Ожидаемый результат:

```text
MCP-соединение установлено.
Доступные инструменты (3):
- greet: Возвращает персональное приветствие.
- get_current_time: Возвращает текущее время на сервере в формате ISO 8601.
- calculate_sum: Складывает два числа и возвращает их сумму.
Клиент ждёт команду. Введите help для подсказки.
mcp> greet Анна
greet → {"greeting":"Привет, Анна!"}
mcp> sum 19 23
calculate_sum → {"sum":42}
mcp> time
get_current_time → {"currentTime":"2026-09-21T...Z"}
mcp> exit
```

## Как использовать с внешним MCP-сервером

Для внешнего сервера меняется только транспорт и добавляется его авторизация.
Например, вместо `StdioClientTransport` используется HTTP-транспорт с URL
MCP-сервера. После подключения `client.listTools()` и `client.callTool()`
работают по тому же принципу.
