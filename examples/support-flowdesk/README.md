# Исторический пример FlowDesk

Вымышленный продукт первоначальной реализации дня 33. Корпоративный SSO, тарифы и ошибки описывают только этот пример и не относятся к MyFamily.

Основной сервис использует support/myfamily/knowledge/ с документацией MyFamily и support/myfamily/crm.demo.json. Этот каталог не индексируется. Для эксперимента с FlowDesk нужны отдельный corpus/index и соответствующий JSON: нельзя подключать этот CRM к знаниям MyFamily. Исходный support/crm.demo.json сохранён для совместимости, но по умолчанию больше не используется.
